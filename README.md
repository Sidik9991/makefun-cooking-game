# Ember Pass Kitchen — juggle the burn: 4 burners, 12 recipes, 3 stations, 90-second rush

A 90-second service rush in a kitchen of your own: grab ingredients from the counter, chop what needs chopping, drop each recipe's ingredients into a pot — and juggle the burn, because a finished dish burns in 8 seconds if you leave it on the burner. Twelve recipes from eight ingredients across three stations (chop, stove, plate), tickets that tick down on the order board, and a combo that grows with every fast serve. Keyboard + mouse, canvas-drawn art, synthesized sounds, no network requests.
